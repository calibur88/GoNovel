## 参考项目调研结论(obsidian-webnovel-assistant)
- 规模:约 195 个 TS 文件,28 个服务,10 个视图,12+ 弹窗;架构为主类门面 + ServiceRegistry(服务注册中心)+ PluginBootstrapper(分阶段启动/卸载)。
- 功能四组:写作核心(主页/工作台/沉浸模式/章节管理)、创作辅助(伏笔/时间线/设定图谱/任务/便签/搜索)、数据统计(字数/目标/专注热力图/写作历程)、质量扩展(校对/排版/护眼/OBS/移动端)。
- UI 要点:
  - 创作主页:markdown 文件 + 代码块处理器渲染(非独立 View),全宽仪表盘 + ResizeObserver 响应式。
  - 写作工作台:ItemView,页头(作品切换+操作按钮)→ 六看板 tab → 过滤条 → 看板主体;tab 切换持久化到设置。
  - 章节卡片:按卷分组折叠,行内改名/行内编辑摘要、状态徽章、伏笔/设定 badges、字数进度。
  - 侧栏面板与 12+ Modal 弹窗体系。
- 交互经验:
  - 纯事件驱动 + 统一防抖(AdaptiveDebounceManager.debounceFixed)。
  - 自定义 workspace 事件总线(book-changed / tasks-changed / notes-changed)跨视图联动。
  - 渲染防闪烁:离屏 buffer → DocumentFragment swap;currentRenderId + isReloadingBoard 防竞态;保留滚动位置。
  - 书上下文自动跟随:active-leaf-change + findBookRoot;手动切换广播事件。
  - 拖拽:HTML5 DnD + TouchDragPolyfill,MIME application/wn-chapter-path,跨卷禁止。
  - 筛选:WorkbenchFilterIndex 正反向索引,200ms 防抖,IME 兼容。
  - 工程规范:无 innerHTML(防 XSS)、CSS 前缀 wn- / homepage-、Pick<Service> 接口收窄。
