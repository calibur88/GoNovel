# GoNovel

> 本文是项目的 README 主页。

**GoNovel** 是一个 Obsidian 小说管理插件：以简洁 UI 与重管理为核心，提供创作主页、写作工作台（六看板）、章节卡片与弹窗体系，不做花哨的写作编辑功能。

- **创作主页**：全宽仪表盘，动态欢迎语、数据面板、作品列表，一键新建与导入作品；
- **写作工作台**：页头 + 六看板 tab（章节 / 时间线 / 伏笔 / 设定 / 任务 / 写作历程）+ 过滤条 + 看板主体；
- **章节卡片**：卡片式章节管理，按卷分组，行内改名与摘要编辑，状态标记与字数进度；
- **弹窗体系**：新建作品、导入、目标设置、高级搜索、章节合并、拆分冲突确认等统一弹窗；
- **宿主可插拔**：宿主 SDK 只在 `host/`，遵循七层分层架构，换宿主只动 `host/`。

> **版本兼容性**：当前版本与上一版本完全兼容，不涉及语法变更，已有配置可沿用。

版本信息：
- 主版本号：0.1.0
- 项目标识：`go-novel`
- 最低依赖：Obsidian 1.4.0

## 安装

1. 构建插件（或下载发布产物）；
2. 将 `main.js`、`manifest.json`、`styles.css` 复制到 `.obsidian/plugins/go-novel/`；
3. 重启 Obsidian 并在第三方插件中启用 GoNovel。

## 快速开始

1. 命令面板（`Ctrl/Cmd+P`）搜索 `GoNovel`；
2. 执行「打开创作主页」或「打开写作工作台」；
3. 在创作主页点击「新建作品」开始管理你的小说。

## 核心功能

1. **创作主页**：全宽仪表盘，动态欢迎语、今日进度、作品卡片按状态分组、数据面板，响应式切单/双列；
2. **写作工作台**：页头（作品切换 + 操作按钮）→ 六看板 tab → 过滤条 → 看板主体，tab 切换持久化到设置；
3. **章节卡片**：标题（行内改名）、状态徽章、摘要（行内编辑）、伏笔/设定 badges、字数进度；
4. **弹窗体系**：新建作品、导入、目标设置、高级搜索、章节合并、拆分冲突确认等统一弹窗管理。
